# Aurantium

Aurantium is a desktop market terminal for Windows and macOS. It runs
locally and keeps your data private: no accounts, no telemetry, no cloud sync.

**Download:** [latest release](https://github.com/pedroivorocholi/aurantium/releases/latest)

This repository holds only the signed release installers and the update feed
(`appcast.xml`) that installed copies check for new versions. The source code
is not public.
